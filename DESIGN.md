# EdgeSync FieldKit design record

## Shipped direction

Field Synchronization Instrument makes network tension and recovery state spatial. A device bank feeds a dominant node-link topology, while a dark resolver rail preserves conflict lineage and the next safe action. Concept seed `40ecb42a` established the direction.

## Visual system

- Canvas `#E8E5DC`
- Working surface `#F7F5ED`
- Ink `#171A18`
- Conflict signal `#B62F27`
- Route signal `#205B44`

The field-paper surface, hard rules, route geometry, stamped status language, and resolver rail create a distinct operational-instrument character.

## Interaction and state model

Online, degraded, offline, and empty fixtures alter the written status, device counts, route topology, packet tape, conflict lineage, and recommended action coherently. Selecting a device updates the recovery record. Conflict resolution remains an external operator action and is never silently guessed.

## Responsive and accessible behavior

Desktop shows device state, topology, and resolver together. Mobile becomes a device-to-selected-record-to-route sequence so the conflict and safe action appear before the topology. Device and topology controls expose selected state with `aria-pressed`, focus is visible, status never relies on color alone, and both desktop and mobile avoid page-level overflow.

## Truth boundary

Every device, location, record, sequence, and outcome is synthetic. The interface demonstrates deterministic fixtures and no control performs an external action.
